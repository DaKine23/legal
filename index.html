Lokale Spieldaten bleiben gespeichert, bis der Nutzer die App-Daten beziehungsweise Websitedaten löscht oder die App deinstalliert. Da beide Spiele keine Benutzerkonten und keine serverseitige Speicherung verwenden, existieren keine extern gespeicherten Kontodaten, die separat gelöscht werden müssten.

2. No collection or sharing of personal data

Cloudstrike and Shroomingz do not collect, transmit, sell, or share personal or sensitive user data. The games contain no advertising, analytics, user accounts, subscriptions, in-app purchases, or tracking technologies. They request no Internet permission and are fully playable offline.

3. Local game data

The games store only local game data:

  • Cloudstrike: the five best scores, pilot initials, earned ranks, the most recently used pilot initials, and the selected size of the on-screen analog stick.
  • Shroomingz: current campaign progress.

This data remains in the device's private app storage or the web version's local browser storage. It is not accessible to the developer and is not transmitted to the developer or any third party.

4. Retention and deletion

Local game data remains until the user clears the app data or website data, or uninstalls the app. Neither game uses accounts or server-side storage, so there is no remotely stored account data requiring a separate deletion request.

5. Permissions and security

The games request no access to contacts, location, camera, microphone, files, or other personal device data. The operating system's private app storage protects local settings and game progress.

6. Children

The games do not knowingly collect data from children or any other users.
